TR-8 — a CPU from discrete transistors

An 8-bit CPU designed from discrete NPN transistors and resistors — RTL gates, a diode-matrix ROM, and an assembler that generates it.

Architecture

  • Registers, ALU and control built from those blocks only.
  • Programs written in assembly; the assembler outputs the diode pattern for the ROM.
