Low-noise reference filter

A 4th-order low-pass with a cutoff of a few hertz for a 5 V reference signal — plus a digital loop that trims its drift against an ADR1000.

Signal
5 V in · 10 V out
Filter
4th-order LP, ~Hz cutoff
Converters
LTC2357-18 ADC · DAC
Tools
KiCad

Idea

Heavy filtering removes noise but lets slow drift through. An 18-bit ADC compares the output with an ADR1000 reference, an Arduino Nano decides, and a DAC adds a very small, bidirectional correction at the filter input.

Design choices

  • C0G / film capacitors only in the filter path — size traded for dielectric absorption and stability.
  • Sense path kept minimal: output compared directly with the reference through ADA4523 amplifiers and LT5400 matched networks.
  • DAC correction applied as a DC lift centred on 5 V, so no pull-up from a noisy supply touches the reference node.
  • Separate reference board with four ADR1000s in parallel.
